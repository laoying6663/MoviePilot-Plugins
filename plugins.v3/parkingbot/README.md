# 不可躺自动抢车位（ParkingBot）

自动把车停到他人私家车位上赚金币，停够设定时长后自动挪车结算收益。
登录身份复用 MoviePilot「站点管理」里 `tangpt.top` 站点已保存的 Cookie，不重复维护第二份登录态。

## 前置条件

1. 在 MoviePilot「站点管理」中添加并成功登录 `tangpt.top`（能通过连通性测试）。
   插件会用这份主站 Cookie 自动换取游戏会话，不需要你手填任何 Cookie。
2. 账号在游戏站点 `https://qcw.tangpt.top/` 至少拥有 1 辆车辆。

## 登录是怎么处理的

游戏站 `qcw.tangpt.top` 是独立子域，**主站登录 Cookie 不能直接用于游戏接口**。
插件的处理方式是：

1. 读取「站点管理」中 `tangpt.top` 站点已保存的 Cookie；
2. 请求主站 SSO 接口 `https://www.tangpt.top/tp-open-connect/sso/generate?app_id=app_DapZ0NZ28EFu`，
   逐跳跟随跳转链，收集每一跳下发的 `Set-Cookie`；
3. 得到游戏站会话 Cookie 后缓存 1 小时，期间直接复用；失效则自动重取。

全程不涉及账号密码、不涉及验证码，因此没有连续登录失败封 IP 的风险。
主站 Cookie 掉线时，由 MoviePilot 站点管理侧负责更新，插件下一轮会自动用新 Cookie 重试。

如果主站 SSO 不可用，仍可在配置里手动填写游戏 Cookie 兜底（该值优先级最高）。

## 配置项

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 启用插件 | 关闭 | 插件总开关 |
| 立即执行一次 | 关闭 | 保存配置后延迟 3 秒跑一轮，便于验证 |
| 登录失效时通知 | 开启 | Cookie 失效只在连续失败期间提醒一次，不每轮刷屏 |
| 执行周期 | `*/5 * * * *` | 每轮先挪车再停车 |
| 停满多少分钟挪走 | `10` | 游戏规定最少停 10 分钟才允许挪走，填更小的值按 10 分钟计 |
| 最多同时停放车辆数 | `1` | 同时停放越多收益越高，但被贴条风险也越大 |
| 游戏 Cookie | 空 | 一般无需填写。留空时自动用「站点管理」的主站 Cookie 换取游戏会话；仅在主站 SSO 不可用时才需要手动粘贴 `qcw.tangpt.top` 的 Cookie |

## 每轮执行逻辑

1. 解析登录 Cookie：手填值 > 未过期缓存 > 现走一次主站 SSO。
2. 读取游戏状态，失败时清除缓存并按「登录失效」处理（连续失败只通知一次）。
2. **挪车**：遍历名下所有停车中的车辆，停够设定时长的调用 `unpark.php` 结算收益，释放出的车辆立即回到空闲池。
3. **停车**：把空闲车辆按每分钟收益从高到低，依次停到他人空闲的私家车位；目标车位在候选集中随机挑选，避免长期压在同一位车主身上。

目标车位筛选条件：不属于自己、没有车、且不是爱心车位。

## 规则要点

- 停在别人私家车位超过 5 分钟，车位主人可以贴条；此时收益按 70% / 30% 分给车位主人和停车者。
- 单车位收益上限 3000 金币，停满 10 分钟才允许挪走，超过 12 小时未挪走会被系统自动清理。

## 界面

**插件详情页**（插件列表 → 不可躺自动抢车位）分五块：

1. **账户头卡** —— 昵称与等级、车辆上限、最近一轮结果、本进程累计挪车收益
2. **四个指标块** —— 金币、魔力、停车中车辆数、待结算金币
3. **车辆状态表** —— 车型 / 金每分钟 / 状态 / 已停分钟 / 待结算金币。
   停车中的车辆排在前面，按每分钟收益从高到低；「待结算」是挪车时能拿到的预估金币（已按单车位 3000 上限封顶）
4. **我的车位表** —— 每个车位当前被谁占用，空闲则显示「空闲」
5. **执行历史表** —— 最近 20 轮的时间、新停放数、挪走数、本轮收益（最多保留 50 轮）

**主面板状态卡** —— 主仪表盘上会多一块卡片，显示昵称等级、金币、停车中数量和待结算金额。

以上数据来自每轮执行结束时落盘的账户快照，打开页面不会再去请求游戏接口，因此翻页很快、也不会因为游戏暂时不可达而白屏。

## 注意

- 本插件只做自动停车与自动挪车，**不会**自动贴条或举报他人车辆。
- 挪车时间依赖 MoviePilot 时区，请确保「设定 → 常规设置」里的时区与游戏页面显示的时区一致，
  否则停车时长会算错。
- 自动操作第三方站点可能与该站点的使用条款冲突，请自行评估后使用。
