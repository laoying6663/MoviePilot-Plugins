# 企业微信通知

把 MoviePilot 的通知推送到**企业微信自建应用**，并支持在企业微信里执行远程命令。

## 能做什么

- **通知推送**：监听宿主的 `NoticeMessage` 事件，按消息类型筛选后转发到企业微信
- **图文消息**：带封面图的通知按图文（news）消息下发
- **长文分块**：超过企业微信单条上限的正文按 2048 字节切分，不切断多字节字符
- **消息回调**：接收企业微信推来的消息，校验 SHA1 签名并 AES 解密
- **远程命令**：在企业微信里发 `/wecom_status`、`/wecom_test`、`/help`
- **控制菜单**：按已注册命令自动在企业微信应用里创建菜单
- **管理员白名单**：限制谁可以执行斜杠命令和菜单
- **转发代理**：2022-06-20 之后创建的自建应用需要固定公网 IP，插件支持填代理地址

## 与宿主内置「企业微信」渠道的区别

插件受宿主开发合同限制，**不能向 `NotificationChannel` 枚举注册新的通知渠道**。因此：

| 能力 | 内置渠道 | 本插件 |
| --- | --- | --- |
| 通知推送 | ✅ | ✅ |
| 消息回调 / 远程命令 | ✅ | ✅（仅本插件注册的命令） |
| 自动菜单 | ✅ | ✅ |
| 在 `设定 → 通知` 里作为系统渠道出现 | ✅ | ❌ |
| 使用宿主内置斜杠命令（如 `/site_signin`） | ✅ | ❌ |

第 4、5 两条是宿主合同的硬限制，不是实现取舍：回复消息由插件自己调企业微信 API 发送，
不会经过宿主 `post_message`，所以宿主命令注册表里的命令无法从本插件触达。
非命令消息会以 `EventType.UserMessage` 广播，其它插件仍可监听。

## 配置

在插件配置页填写，字段与 MoviePilot 内置企业微信渠道一一对应：

| 字段 | 说明 |
| --- | --- |
| 企业ID | 企业微信后台 `我的企业 → 企业信息` |
| 应用 AgentId | 企业微信后台 `应用管理 → 自建` |
| 应用 Secret | 同上 |
| 代理地址 | 消息转发代理，留空直连 `https://qyapi.weixin.qq.com` |
| Token | 企业微信应用 `接收消息` 页面生成 |
| EncodingAESKey | 同上 |
| 接收人 | 指定 userid，留空发给应用可见的全部成员 |
| 管理员白名单 | 可执行命令的用户 ID，多个用英文逗号分隔 |
| 类型 | 通知类型筛选，留空表示全部 |

> 代理地址是**转发**代理，不是反向代理。它需要把 `/cgi-bin/gettoken`、
> `/cgi-bin/message/send`、`/cgi-bin/menu/create` 转发到 `qyapi.weixin.qq.com`，
> 并把代理机的真实 IP 加入企业微信应用的 IP 白名单。

## 启用消息回调

1. 填好企业ID / 应用Secret / 应用AgentId / Token / EncodingAESKey，保存配置
2. 在企业微信应用 `接收消息` 页面填入：

```text
http(s)://<你的域名>:<端口>/api/v1/plugin/WecomNotify/wecom
```

需要公网可访问的地址并做好端口转发。保存成功即表示验证通过（插件会返回解密后的
`echostr`，企业微信据此判定 URL 有效）。

3. 打开控制菜单开关，插件会按已注册命令创建应用菜单

## 命令

| 命令 | 说明 |
| --- | --- |
| `/wecom_status` | 查看当前配置与连通性 |
| `/wecom_test` | 发送一条测试消息 |
| `/help` | 列出全部可用命令 |

管理员白名单为空时，任何企业微信用户发来的斜杠命令都会被执行。生产环境请务必配置。

## 依赖

回调加解密需要 `pycryptodome`。MoviePilot 主程序已内置该依赖，插件因此不额外声明。
若环境缺失，插件仍可正常加载，推送功能不受影响，仅回调功能不可用，面板与日志会给出提示。

## 调试

- 插件详情页可查看当前配置、最近一次发送结果和加解密依赖状态
- 插件接口 `GET /api/v1/plugin/WecomNotify/status` 可返回运行状态（需登录）
- 日志中所有输出均带 `[企业微信通知]` 前缀
